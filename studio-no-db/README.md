# Studio (No DB)

A lightweight, zero-backend "studio" for content management. No server, no database — everything is stored in your browser's localStorage with JSON export/import.

## Features
- Content types (schemas): create/edit types and fields (string, text, number, boolean, date)
- Documents: create, edit, delete per type
- Preview panel for quick visualization
- Theme toggle (dark/light)
- Export/Import full state as JSON
- Reset all data

## Getting started
- Open `index.html` in a browser
- Create new content types under `Schemas`
- Manage content under `Content`
- Export/Import under `Export/Import`

## Notes
- Data persists only in the browser where you use it
- Use Export to back up your data
